Sometimes an image, a sentence, a place, or a sound stays with me longer than expected. This is a place to set those things down.

Not a catalogue, not quite a diary. More like leaving a window open: a few collected fragments, gathered when there is something worth keeping.

The first note is simply this: **begin anywhere**.
